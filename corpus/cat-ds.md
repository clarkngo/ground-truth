# Course Catalog: Data Science

All DS courses are 4 credits except DS 590, which is 8 credits.

## DS 510 Statistical Learning
Regression, classification, resampling and regularization. Prerequisite: admission to the M.S. in Data Science.
Offered: Fall.

## DS 520 Applied Machine Learning
End-to-end machine learning projects on real data. Prerequisite: DS 510. Offered: Winter.

## DS 530 Data Visualization and Communication
Communicating results to technical and non-technical audiences. Prerequisite: admission to the M.S. in Data Science.
Offered: Fall, Spring.

## DS 590 Data Science Capstone
A sponsored project with a final report and presentation. 8 credits. Prerequisites: DS 520 and DS 530.
Offered: Spring, Summer.
