# Course Catalog: Computer Science

All CS courses are 5 credits.

## CS 160 Programming in Python
Programming fundamentals in Python. Includes a lab. No prerequisites. Offered every quarter.

## CS 210 Data Structures
Lists, trees, graphs, hashing and complexity. Prerequisite: CS 160. Offered: Fall, Winter, Spring.

## CS 230 Computer Systems
Memory, processes, concurrency and networking basics. Prerequisite: CS 210. Offered: Winter, Spring.

## CS 310 Algorithms
Algorithm design and analysis. Prerequisites: CS 210 and MATH 201. Offered: Fall, Spring.

## CS 340 Databases
Relational design, SQL and transactions. Prerequisite: CS 210. Offered: Fall, Winter.

## CS 450 Computer Science Capstone
Team software project. Prerequisites: CS 310 and senior standing. Offered: Winter, Spring.
